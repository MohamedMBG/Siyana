# Back-office React

Ce dossier est réservé à l’interface web React et TypeScript. Le projet React n’est pas encore initialisé.

Dans `src/`, placer le routage et la configuration de l’application dans `app/`. Regrouper les pages, composants et appels d’API propres à chaque fonctionnalité dans `features/` (équipements, demandes d’intervention, ordres de travail, préventif, stock et pilotage). Réserver `shared/` au client HTTP, aux styles et aux composants communs.
